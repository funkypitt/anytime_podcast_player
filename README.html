les méditations

Méditations guidées audio pour enpleineconscience.ch.

Overview

Application mobile (Android, iOS) de méditations guidées pour enpleineconscience.ch. L'app propose un catalogue fixe de podcasts de méditation guidée pré-configurés, organisés par catégories (bodyscan, respiration, pleine conscience, etc.) avec lecture audio en arrière-plan.

Ce projet est un fork de Anytime Podcast Player par Ben Hills, adapté pour la diffusion de méditations guidées.

Features

  • Catalogue fixe de podcasts de méditation (pas de recherche externe)
  • Lecture audio en arrière-plan (audio_service)
  • Téléchargement pour écoute hors-ligne
  • Rebranding complet : icônes, couleurs, écrans de lancement
  • Interface simplifiée pour l'écoute de méditations
  • Suppression des fonctionnalités non pertinentes (import/export OPML, choix de moteur de recherche)
